# BOTYARA PROJECT CONTEXT

## О проекте

BOTYARA — AI-платформа для работы с промптами, изображениями, музыкой и видео.

Основные направления:
- генерация промптов;
- AI-комнаты;
- галерея;
- профили пользователей;
- уровни XP;
- достижения;
- платные функции.

## Стек

Frontend:
- React
- Vite
- JavaScript
- CSS Modules / обычный CSS

Backend:
- FastAPI
- PostgreSQL
- Valkey

Инфраструктура:
- Timeweb Cloud
- GitHub

## Правила работы

ВАЖНО:

Перед изменением кода:
1. Анализировать существующую архитектуру.
2. Не удалять существующий функционал.
3. Не переписывать большие части без согласования.
4. Сохранять текущий дизайн.
5. Проверять зависимости.

## Запрещено

Не менять:
- систему авторизации;
- API без проверки;
- структуру базы данных;
- существующие страницы без анализа.

## Стиль разработки

Код должен быть:
- чистым;
- масштабируемым;
- понятным;
- готовым к дальнейшему развитию.
